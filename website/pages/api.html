Pool API

Read pool statistics, historical data and live updates. All endpoints are read-only and require no authentication.

GET · JSON

/api/stats

Current pool and worker statistics, including hashrate, immature rewards and total paid per worker.

GET · JSON

/api/pool_stats

Historical pool hashrate, worker counts and block statistics used by the charts.

GET · EVENT STREAM

/api/live_stats

Server-sent events with updated statistics at the pool's configured refresh interval.

const events = new EventSource('/api/live_stats');
events.onmessage = function(event) {
    const stats = JSON.parse(event.data);
    console.log(stats.pools);
};
